# Aeromon launcher artwork

The application uses Brian's original Aeromon server emblem for its window, Windows executable, macOS application icon, and Linux package icon. Its pack thumbnail is the original Aeromon cover. The icon was converted to ICO/ICNS formats without redesigning the source artwork.

Sources: `D:\Projects\Pixelmon\branding\aeromon-server-icon-master.png` and `aeromon-modpack-cover-master.png`.

Bundled assets: `src/main/resources/branding/icon.png`, `icon.ico`, `icon.icns`, `cover.png`, and `launcher-banner.png`.

The banner was generated with the built-in image generation tool using the original cover and emblem as references. Final prompt:

> Widescreen 16:9 background artwork for the Aeromon desktop Minecraft modpack launcher. Use the supplied original Aeromon cover as the visual canon: richly detailed voxel floating islands, teal and gold Create Aeronautics airship, lush Pixelmon town, blue sky and luminous clouds. Create a professional cinematic landscape expansion in a wide composition: large detailed teal-and-gold propeller airship toward the right, floating island village below, clouds and distant islands; leave the left third atmospheric and uncluttered for real UI text layered later. Match the established art style and brand colors exactly. Background art only: no text, lettering, logo, UI panels, buttons, or watermarks. The emblem is palette reference only; do not redesign it.

The UI uses a restrained navy surface, cyan actions, gold Play button, legible typography, original pack tile and a real release/status area. No Void's Wrath artwork is used.
