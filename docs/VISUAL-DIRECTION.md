# Visual direction

Aeromon Launcher should feel like a dedicated game portal: expressive, atmospheric, and a little nostalgic. The reference is the sense of discovery in the [Void's Wrath launcher](https://voidswrath.com/voidlauncher/), especially its prominent pack navigation and separate news and server areas. Aeromon will use its own layout, marks, illustrations, and copy.

## First screen

- A large Aeromon world illustration and a clear **Play Aeromon** action anchor the home screen.
- A side rail presents the pack, news, servers, and settings. Pack art is prominent and easy to scan.
- A compact status strip shows installed pack version, available update, download progress, and `mc.aeromon.cc` availability.
- Release notes and event news feel like part of the world, rather than an administrative dashboard.

## Look and feel

- Dark ink and deep teal surfaces, warm parchment or stone accents, and restrained mint highlights from Aeromon branding.
- Framed panels, illustrated pack art, subtle texture, and crisp typography. Retro game character without tiny text or dense controls.
- Motion supports the theme: a short launch transition, responsive hover states, and smooth download progress. Reduced-motion settings disable decorative animation.
- Controls remain obvious: Install, Update, Play, Repair, and Settings should be recognizable at a glance.

## Interface states to design

1. First install and account sign-in.
2. Ready to play.
3. Update available with release notes and size.
4. Downloading and verifying files.
5. Recoverable error with Repair and log export.

Use original Aeromon assets. Do not reuse Void's Wrath artwork, logo, or UI screenshots in the shipped launcher.
