Install on Arch Linux

Run these commands in a terminal to download and install the Arch package:

curl --fail --location --retry 3 https://aeromon.cc/downloads/aeromon-launcher-bin-1.0.24-1-x86_64.pkg.tar.zst --output aeromon-launcher-bin-1.0.24-1-x86_64.pkg.tar.zst
sudo pacman -U ./aeromon-launcher-bin-1.0.24-1-x86_64.pkg.tar.zst

Open Aeromon Launcher from your applications menu. Java is included. Future launcher and pack updates install in your user folder.

Release status

Aeromon Launcher 1.0.24 is available. Choose your platform above. Installers are unsigned; Windows and macOS may show a publisher warning. A Prism Launcher pack is also available on this page.

Microsoft sign-in and online multiplayer are available. The launcher updates itself to the current release; choose Stable for mc.aeromon.cc or Test for test.aeromon.cc.

Launcher update manifests use Aeromon's Ed25519 signature and pack files carry SHA256 hashes. That signature is not operating-system publisher signing. Windows Authenticode and Apple notarization are not configured, and Linux package signing is not configured.
